# StageCue

StageCue is a free desktop timer and cue display for live productions, presentations, events, and broadcasts.

## Download

### Windows

[Download StageCue 0.1.1 for Windows (64-bit)](https://github.com/adetomilola/stagecue-releases/releases/download/v0.1.1/StageCue_0.1.1_x64-setup.exe)

### macOS

The hardened 0.1.1 macOS package will be added after it has been rebuilt and tested on a Mac.

## Installation notes

StageCue is currently distributed without a paid code-signing certificate. Windows SmartScreen or macOS Gatekeeper may therefore display an unrecognized-developer warning. Only download StageCue from this repository.

## About this repository

This public repository contains official packaged releases only. The application source repository remains private.
